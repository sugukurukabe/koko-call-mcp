## ChatGPT受入ケース設計（未実行）

| ケース | 合格条件 |
|---|---|
| **接続と再接続** | 正規URLからOAuth完了、対象ツール認識、切断後の認可動作が説明と一致 |
| **小規模検索** | 最大3件の条件を守り、返却データと表示の案件Key・機関が一致 |
| **詳細復元** | 選択案件と詳細が一致。スナップショットを原本本文と誤表示しない |
| **選択CSV** | 異なる機関の2件のみ、16列、Key/機関/理由が対応。受信データと取得データを区別して保存 |
| **順位付け・URL抽出** | スコアの理由が対象案件に対応。不明な参加条件を創作せず、本文取得有無を正確に表示 |
| **該当なし・通信失敗** | 空結果と障害を区別。無限再試行や成功通知の誤表示なし |
| **期限切れ/改ざん参照** | 安全に拒否し、必要な回復操作を明示 |
| **UI操作** | 狭幅、キーボード、読み込み状態、保存/コピー非対応時の案内を確認 |

※実行時は対象ビルド・日時・接続・期待値・実結果・証拠を記録する。自然に変わる公告件数を固定期待値にしない。既存の正式Gate 1の35条件とは別の提出前チェックであり、代替の全面合格宣言をしない。
