# MCP 2026-07-28 RC 仕様読み取りメモ / MCP 2026-07-28 RC Notes / Catatan Spesifikasi MCP 2026-07-28 RC

## 日本語

- `2026-07-28` は 2026-05-21 に Release Candidate がロックされ、2026-07-28 に正式公開予定。`2025-11-25` からの破壊的変更を含む。
- コアは stateless へ移行する。`initialize` / `initialized` handshake と `Mcp-Session-Id` は廃止され、protocol version・client info・capabilities は各リクエストの `_meta` へ移る。
- Streamable HTTP は `Mcp-Method` と `Mcp-Name` header を routing 用に使う。JP Bids MCP と Public MCP JP Gateway は header が存在する場合に JSON-RPC body との不一致を `400` で拒否する。
- Tools / Prompts / Resources の list/read 結果には `ttlMs` / `cacheScope` が導入される。SDK 対応後に server/discover と一緒に有効化する。
- Tasks は core から `io.modelcontextprotocol/tasks` extension へ移動する。現時点では本 repo は実験版 Tasks に依存していないため実装しない。
- Elicitation は MRTR (`inputRequired` + `requestState`) パターンへ移る。本 repo は elicitation 未使用。
- Roots / Sampling / Logging は deprecated。JP Bids の document extraction は sampling fallback を維持しつつ、Vertex AI Gemini direct mode への移行方針を ADR-0024 に記録する。Gateway の runtime 観測は MCP Logging ではなく stderr / metrics / 将来 OpenTelemetry を正とする。
- OAuth は RFC 9207 `iss` を authorization response に含める方向へ強化される。JP Bids OAuth は redirect response と発行 JWT に `iss` を追加済み。
- Missing resource の error code は `-32002` から JSON-RPC 標準の `-32602` に変更される。本 repo に `-32002` のハードコードはない。

## English

- `2026-07-28` is a release candidate locked on 2026-05-21 and scheduled for final publication on 2026-07-28. It includes breaking changes from `2025-11-25`.
- The core protocol becomes stateless. `initialize` / `initialized` and `Mcp-Session-Id` are removed; protocol version, client info, and capabilities move into per-request `_meta`.
- Streamable HTTP uses `Mcp-Method` and `Mcp-Name` for routing. JP Bids MCP and Public MCP JP Gateway reject requests with `400` when these headers disagree with the JSON-RPC body.
- List/read results for Tools, Prompts, and Resources gain `ttlMs` / `cacheScope`. We will enable them with `server/discover` after SDK support lands.
- Tasks moves from core to the `io.modelcontextprotocol/tasks` extension. This repo does not depend on experimental Tasks today, so no runtime implementation is added.
- Elicitation moves to the MRTR (`inputRequired` + `requestState`) pattern. This repo does not use elicitation.
- Roots, Sampling, and Logging are deprecated. JP Bids keeps sampling fallback for document extraction while ADR-0024 records the move toward Vertex AI Gemini direct mode. Gateway observability should rely on stderr, `/metrics`, and future OpenTelemetry rather than MCP Logging.
- OAuth is hardened toward RFC 9207 `iss` in authorization responses. JP Bids OAuth now includes `iss` in redirect responses and issued JWTs.
- Missing resource errors move from `-32002` to JSON-RPC standard `-32602`. This repo has no hardcoded `-32002`.

## Bahasa Indonesia

- `2026-07-28` adalah release candidate yang dikunci pada 2026-05-21 dan direncanakan final pada 2026-07-28. Versi ini membawa perubahan breaking dari `2025-11-25`.
- Core protocol menjadi stateless. `initialize` / `initialized` dan `Mcp-Session-Id` dihapus; versi protokol, info klien, dan capability berpindah ke `_meta` pada setiap request.
- Streamable HTTP memakai header `Mcp-Method` dan `Mcp-Name` untuk routing. JP Bids MCP dan Public MCP JP Gateway menolak request dengan `400` jika header tersebut tidak cocok dengan body JSON-RPC.
- Hasil list/read untuk Tools, Prompts, dan Resources mendapatkan `ttlMs` / `cacheScope`. Ini akan diaktifkan bersama `server/discover` setelah SDK mendukungnya.
- Tasks berpindah dari core ke extension `io.modelcontextprotocol/tasks`. Repo ini tidak bergantung pada Tasks eksperimental saat ini, jadi tidak ada implementasi runtime baru.
- Elicitation berpindah ke pola MRTR (`inputRequired` + `requestState`). Repo ini belum menggunakan elicitation.
- Roots, Sampling, dan Logging deprecated. JP Bids tetap mempertahankan fallback sampling untuk ekstraksi dokumen, sementara ADR-0024 mencatat arah migrasi ke Vertex AI Gemini direct mode. Observability Gateway memakai stderr, `/metrics`, dan OpenTelemetry masa depan, bukan MCP Logging.
- OAuth diperkuat dengan `iss` RFC 9207 pada response authorization. OAuth JP Bids kini menambahkan `iss` pada redirect response dan JWT yang diterbitkan.
- Error missing resource berpindah dari `-32002` ke standar JSON-RPC `-32602`. Repo ini tidak memiliki hardcode `-32002`.
