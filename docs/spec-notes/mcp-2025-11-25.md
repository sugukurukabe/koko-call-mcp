# MCP 2025-11-25 仕様読み取りメモ / MCP 2025-11-25 Notes / Catatan Spesifikasi MCP 2025-11-25

## 日本語

- 基本プロトコルは JSON-RPC 2.0。HTTP transport では `MCP-Protocol-Version` を初期化後のリクエストに含める。
- サーバーは初期化時に実装済み capability だけを宣言する。JP Bids MCP v0.7+ は `tools`, `resources`, `prompts`, `completions` を提供する。`logging` は実装していないため宣言しない。`tasks` は長時間処理が入るまで宣言しない。
- Streamable HTTP は `/mcp` 単一エンドポイントで `POST` を処理する。SSE `GET` は `405` を返す（仕様準拠）。プロトコルバージョン `2025-11-25` 以外は `400` で拒否する。
- Tool result は `content` と `structuredContent` を併用する。構造化出力を返すToolは `outputSchema` と実結果の整合性を保つ。
- `get_bid_detail` は公式公告ページと添付ファイルを `resource_link` content として返す（MCP 2025-11-25 spec 準拠）。
- `search_bids`/`list_recent_bids`/`search_bids_app` は structuredContent.bids を 100 件でキャップし、大きすぎるレスポンスを防ぐ。
- 全17ツールに `title` と `readOnlyHint` / `destructiveHint` を付与（Anthropic Connectors Directory 審査要件）。Investor Radar 追加後も全ツールに同様の annotation を付与する。
- 読み取り専用ツール（KKJ API に書き込まない・外部ストレージを操作しないもの）は `readOnlyHint: true`。`save_search` / `check_saved_search` のみ `readOnlyHint: false`（in-memory state 更新のため）。
- Tools, Prompts, Resources, Resource Templates の list 系は opaque cursor による pagination に対応する仕様だが、静的リストでは `nextCursor` を返さない。

## English

- The base protocol is JSON-RPC 2.0. HTTP transport requests include `MCP-Protocol-Version` after initialization.
- The server declares only implemented capabilities. JP Bids MCP v0.7+ exposes `tools`, `resources`, `prompts`, `completions`. `logging` is not advertised because it is not implemented. `tasks` stays out until long-running workflows exist.
- Streamable HTTP is served from `/mcp` with `POST`. Unsupported SSE `GET` returns `405`. Unsupported protocol versions return `400`.
- Tool results include both `content` and `structuredContent`; structured output tools keep results aligned with `outputSchema`.
- `get_bid_detail` returns `resource_link` content blocks for the official announcement page and attachments (MCP 2025-11-25 spec).
- `search_bids`/`list_recent_bids`/`search_bids_app` cap `structuredContent.bids` at 100 entries to prevent oversized responses.
- All tools have `title` and `readOnlyHint` / `destructiveHint` (Anthropic Connectors Directory requirement), including Investor Radar tools.
- Read-only tools (no writes to KKJ API or external storage) use `readOnlyHint: true`. Only `save_search` / `check_saved_search` use `readOnlyHint: false` (in-memory state updates).
- List operations support opaque cursor pagination per spec, but static lists return no `nextCursor`.

## Bahasa Indonesia

- Protokol dasar adalah JSON-RPC 2.0. Transport HTTP menyertakan `MCP-Protocol-Version` setelah inisialisasi.
- Server hanya mendeklarasikan capability yang benar-benar diimplementasikan. JP Bids MCP v0.7+ menyediakan `tools`, `resources`, `prompts`, `completions`. `logging` tidak diiklankan karena tidak diimplementasikan. `tasks` ditangguhkan sampai ada alur kerja jangka panjang.
- Streamable HTTP dilayani melalui `/mcp` dengan `POST`. SSE `GET` mengembalikan `405`. Versi protokol yang tidak didukung mengembalikan `400`.
- Hasil tool memakai `content` dan `structuredContent`; tool dengan output terstruktur harus konsisten dengan `outputSchema`.
- `get_bid_detail` mengembalikan blok konten `resource_link` untuk halaman pengumuman resmi dan lampiran (spec MCP 2025-11-25).
- `search_bids`/`list_recent_bids`/`search_bids_app` membatasi `structuredContent.bids` pada 100 entri untuk mencegah respons terlalu besar.
- Semua alat memiliki `title` dan `readOnlyHint` / `destructiveHint` (persyaratan Anthropic Connectors Directory), termasuk alat Investor Radar.
- Alat baca-saja (tidak menulis ke KKJ API atau penyimpanan eksternal) menggunakan `readOnlyHint: true`. Hanya `save_search` / `check_saved_search` yang menggunakan `readOnlyHint: false` (pembaruan state in-memory).
- Operasi list mendukung pagination berbasis opaque cursor, tetapi daftar statis tidak mengembalikan `nextCursor`.
